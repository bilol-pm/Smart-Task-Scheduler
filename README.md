# Smart Task Scheduler (Priority Queue DSA Project)

An advanced command-line Task Management System built with **Python**, focusing on Object-Oriented Programming (OOP) and Data Structures and Algorithms (DSA). 

This project implements a custom **Priority Queue** data structure to automatically schedule and prioritize tasks based on their importance.

---

## 🚀 Key Features
* **Custom Priority Queue Implementation:** Tasks are not just added sequentially; they are automatically sorted and managed based on priority levels.
* **Object-Oriented Design:** Clean implementation using standard OOP practices (Classes, Encapsulation, and Magic Methods).
* **Data Persistence:** Tasks are securely saved to and loaded from a local storage file, ensuring no data is lost when the program closes.

---

## 🧠 DSA & Concepts Applied
* **Priority Queue Data Structure:** Managing elements based on assigned priority numbers rather than first-in, first-out (FIFO).
* **Sorting Algorithms:** Using key-based sorting to insert new elements dynamically into their correct algorithmic position.
* **File I/O Handling:** Efficiently serialization and deserialization of objects for persistent memory.
