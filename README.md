# To-Do App

A full-stack to-do app: an HTML/CSS/JavaScript frontend, a FastAPI backend and a SQLite database. Tasks are sorted by priority (1 is the most important).

## Features

- Add tasks with a title, description and priority
- Mark tasks as done and undo
- Delete tasks
- Tasks are stored in SQLite and stay after a restart
- Input validation with Pydantic and clear errors (404, 422)
- Interactive API docs generated by FastAPI

## Tech stack

- **Frontend:** HTML, CSS, JavaScript (`fetch`, async/await, DOM)
- **Backend:** Python, FastAPI, Pydantic, Uvicorn
- **Database:** SQLite (`sqlite3`)

## How it works

```
Browser (frontend)  ->  FastAPI (backend)  ->  SQLite (tasks.db)
```

The page sends JSON requests to the API. The API validates them, reads or writes the database and returns JSON. CORS is enabled for the frontend dev server.

## API

| Method | Path | Description |
|---|---|---|
| GET | `/tasks` | List tasks ordered by priority |
| POST | `/tasks` | Create a task |
| PUT | `/tasks/{task_id}` | Update a task |
| DELETE | `/tasks/{task_id}` | Delete a task |

Example request body for `POST /tasks`:

```json
{"title": "Buy milk", "description": "2 liters", "priority": 1}
```

Interactive docs: http://127.0.0.1:8000/docs

## Run locally

### 1. Backend

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn server:app --reload
```

On macOS or Linux, activate with `source venv/bin/activate`. The database file `tasks.db` is created automatically on the first start.

### 2. Frontend

Open `frontend/index.html` with the VS Code Live Server extension. It must run at `http://127.0.0.1:5500`, because the backend allows only this address (CORS).
